RapidDetect is an open-source FPGA engine, currently under development, for streaming security log analysis at 100 Gbps and beyond. Related work has been presented at GOMACTech:

- *RapidDetect: Lightning-Fast Threat Detection via Hardware-Accelerated Streaming Log Analysis* (2026)
- *Towards Lightning-Fast Threat Detection with Near Data Processing* (2024)
- *Accelerating Snort Regular Expressions on FPGAs with Decomposed Automata* (2021)
